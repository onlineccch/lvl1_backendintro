# Todo App with Authentication and Authorization

This is a simple Todo application built with Express.js, featuring user authentication, authorization, and data validation using JWT (JSON Web Tokens).

## Project Description

This project provides a RESTful API for managing todos. Users can create, read, update, and delete todos. The application also includes user registration and login, securing protected routes with JWT authentication.

## Features

-   **User Authentication:** Users can register and log in with email and password.
-   **JWT Authorization:** Protected routes require a valid JWT for access.
-   **Data Validation:** Input data is validated to ensure data integrity.
-   **CRUD Operations:** Full support for creating, reading, updating, and deleting todos.
- **Protected routes:** Access is granted only to users with valid JWT.
